# Khalid Siddiqui — Medical AI Research Portfolio

A static GitHub Pages website for `https://khalid-siddiqi.github.io/`.

## Files

- `index.html` — main page and content
- `style.css` — visual styling and responsive layout

## Publishing

1. Replace the existing `index.html` in `Khalid-Siddiqi.github.io` with this version.
2. Upload `style.css` to the same repository root.
3. Keep GitHub Pages set to deploy from `main` / `/ (root)`.
4. Open `https://khalid-siddiqi.github.io/` and hard-refresh if your browser shows the old version.

## First edits to make

1. Replace the publication placeholder with the exact paper title, venue, year, DOI and links.
2. Add your Google Scholar and ORCID links.
3. Add 1–2 approved research/project images or architecture diagrams.
4. Add a downloadable CV.
5. Create your first research note and link it from the "Research notes" cards.
6. Replace any project wording that no longer reflects the current status of that project.

## Important

Do not upload patient-identifiable information, private hospital screenshots, unpublished clinical data, or credentials/secrets to this public repository.
